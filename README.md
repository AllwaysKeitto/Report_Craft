# 📊 Информационная система «Конструктор отчетов» (ReportCraft)

> **ReportCraft** — это современная модульная информационная система, предназначенная для автоматизированного формирования, верстки и кастомизации аналитической отчетности.

## 🛠 2. Техническая документация (Архитектура и API)

Система построена по принципу **модульной многослойной архитектуры**, что обеспечивает строгую независимость бизнес-логики от механизмов хранения данных и интерфейса отображения.
### 📂 2.1. Структура проекта
Проект разделен на изолированные контексты backend, frontend и конфигурации окружения:

```text
ReportCraft/
├── backend/                  # Серверная часть приложения (микросервис на FastAPI)
│   └── app/
│       ├── main.py           # Главный инициализационный файл (CORS, роутеры, lifespan-события)
│       ├── api/              # Слой сетевых контроллеров (Endpoints)
│       ├── core/             # Системное ядро (безопасность, хеширование паролей)
│       ├── crud/             # Слой абстракции данных (Data Access Object / DAO)
│       ├── db/               # Конфигурация БД и пула соединений (SQLAlchemy)
│       ├── models/           # Декларативное описание реляционных таблиц (SQLAlchemy)
│       ├── schemas/          # Схемы данных (Pydantic-валидация входящих JSON-пакетов)
│       └── services/         # Бизнес-логика (финансовый API, генератор PDF)
│
├── frontend/                 # Клиентское веб-приложение (Single Page UI)
│   ├── css/                  # Стили оформления, сетка конструктора и UI-элементы
│   ├── js/                   # Асинхронные скрипты взаимодействия с API, движок редактора
│   └── pages/                # Статические веб-страницы интерфейса
│
└── generated_pdfs/           # Локальное изолированное хранилище сгенерированных отчетов
```

## 🐳 3. Руководство по установке (Инсталляция и деплой)

Инструкция предназначена для развертывания системы в изолированном контейнеризированном окружении.

### 💻 3.1. Требования к хост-системе
* **Операционная система:** Windows 10/11 (с поддержкой WSL2), macOS или Linux (Ubuntu/Debian/CentOS).
* **Программное обеспечение:** Установленный пакет **Docker Desktop** или **Docker Engine** со встроенным плагином **Docker Compose**.
* **Сеть:** Свободный сетевой порт `8000` на локальном интерфейсе (`localhost`).

### 🚀 3.2. Процесс автоматического развертывания

Выполните последовательно следующие шаги для инициализации проекта:

1. **Подготовка файлов:** Скопируйте исходный код проекта в рабочую директорию на вашем компьютере.

2. **Переход в корень проекта:** Откройте терминал, консоль или командную строку и перейдите в корневую папку (туда, где находятся файлы `Dockerfile` и `docker-compose.yml`):
   ```bash
   cd /path/to/ReportCraft
   ```

3. **Сборка и запуск контейнеров:** Выполните команду для автоматической сборки Docker-образов, конфигурирования изолированной сети и запуска всех сервисов:
   ```bash
   docker-compose up --build
   ```

4. **Проверка работоспособности:** После успешного запуска бэкенд будет доступен по адресу: [http://localhost:8000](http://localhost:8000), а интерактивная документация API (Swagger) — по адресу: [http://localhost:8000/docs](http://localhost:8000/docs).
